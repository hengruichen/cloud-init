# cloud-init

[![Build Status](https://github.com/canonical/cloud-init/actions/workflows/main.yml/badge.svg)](https://github.com/canonical/cloud-init/actions/workflows/main.yml)
[![Coverage Status](https://coveralls.io/repos/github/canonical/cloud-init/badge.svg?branch=main)](https://coveralls.io/github/canonical/cloud-init?branch=main)
[![Documentation Status](https://readthedocs.org/projects/cloud-init/badge/?version=latest)](https://cloudinit.readthedocs.io/en/latest/?badge=latest)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

Cloud-init is a tool for configuring cloud instances at boot time. It runs on
the first boot of an instance and can be used to configure the system in a
variety of ways, including setting the hostname, installing packages, and
running scripts.

## Documentation

The documentation for cloud-init is available at
https://cloudinit.readthedocs.io/en/latest/.

## Installation

You can install cloud-init from the Ubuntu Universe repository:

```bash
sudo apt install cloud-init
```
