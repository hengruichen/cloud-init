## Overview

The cloud-init package provides a Python-based framework for configuring
virtual machines and cloud instances. It is used to configure systems
during early boot, before the system has been fully booted.

The cloud-init package is intended to be installed on a system that will be
configured remotely. The configuration information is provided to the
system via the network or local storage.
