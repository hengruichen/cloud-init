=================
Code of Conduct
=================

This project adheres to the `Ubuntu Code of Conduct`_. All
participants, contributors, and maintainers are expected to abide by
this code of conduct.

.. _Ubuntu Code of Conduct: https://ubuntu.com/community/codeofconduct

The Ubuntu Code of Conduct applies to all spaces managed by the Ubuntu
Foundation, including but not limited to mailing lists, IRC channels,
and social media platforms. It is expected that all participants will
treat each other with respect and dignity, and that all interactions
will be constructive and professional.

If you believe that you have been subjected to harassment or other
unacceptable behavior, please report it to the Ubuntu Code of
Conduct Committee by emailing `codeofconduct@ubuntu.com`_.
