# 云初始化文件翻譯

此目錄包含對雲初始化文件的繁體中文翻譯。

## 概述

翻譯組織在幾個目錄中：

- [en](en/): 英文翻譯
- [fr](fr/): 法文翻譯
- [ja](ja/): 日文翻譯
- [ko](ko/): 韓文翻譯
- [pt_BR](pt_BR/): 巴西葡萄牙語翻譯
- [ru](ru/): 俄文翻譯
- [zh_CN](zh_CN/): 簡體中文翻譯
- [zh_TW](zh_TW/): 繁體中文翻譯

每個目錄包含一個 `README.md` 文件，描述該目錄中的翻譯。

## 貢獻

如果您想為翻譯做出貢獻，請按照以下步驟進行：

1. 為您的翻譯創建一個新分支
2. 翻譯文件
3. 提交您的更改
4. 將更改推送到您的分支
5. 創建一個拉取請求

請注意，所有翻譯都必須遵守項目的代碼行為準則，並且必須根據項目的許可證條款進行提交。

有關更多信息，請參閱 [雲初始化代碼行為準則](https://cloudinit.readthedocs.io/en/latest/code_of_conduct.html) 和 [雲初始化許可證](https://cloudinit.readthedocs.io/en/latest/license.html)。

## 许可

翻譯在與雲初始化項目相同的條款下進行許可。有關更多信息，請參閱 [LICENSE](LICENSE) 文件。
