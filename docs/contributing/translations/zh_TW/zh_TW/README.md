# 云初始化文档翻译

此目录包含对云初始化文档的繁体中文翻译。

## 概述

翻译组织在几个目录中：

- [en](en/): 英文翻译
- [fr](fr/): 法文翻译
- [ja](ja/): 日文翻译
- [ko](ko/): 韩文翻译
- [pt_BR](pt_BR/): 巴西葡萄牙语翻译
- [ru](ru/): 俄文翻译
- [zh_CN](zh_CN/): 简体中文翻译
- [zh_TW](zh_TW/): 繁体中文翻译

每个目录包含一个 `README.md` 文件，描述该目录中的翻译。

## 贡献

如果您想为翻译做出贡献，请按照以下步骤操作：

1. 为您的翻译创建一个新的分支
2. 翻译文档
3. 提交您的更改
4. 将更改推送到您的分支
5. 创建一个拉取请求

请注意，所有翻译都必须遵守项目的代码行为准则，并且必须根据项目的许可证条款提交。

有关更多信息，请参阅 [云初始化代码行为准则](https://cloudinit.readthedocs.io/en/latest/code_of_conduct.html) 和 [云初始化许可证](https://cloudinit.readthedocs.io/en/latest/license.html)。

## 许可证

翻译在与云初始化项目相同的条款下进行许可。有关更多信息，请参阅 [LICENSE](LICENSE) 文件。
