# Cloud-init Translations

This directory contains the translations for the cloud-init documentation.

## Overview

The translations are organized into several directories:

- [en](en/): The English translations
- [fr](fr/): The French translations
- [ja](ja/): The Japanese translations
- [ko](ko/): The Korean translations
- [pt_BR](pt_BR/): The Portuguese (Brazil) translations
- [ru](ru/): The Russian translations
- [zh_CN](zh_CN/): The Chinese (Simplified) translations
- [zh_TW](zh_TW/): The Chinese (Traditional) translations

Each directory contains a `README.md` file that describes the
translations in that directory.

## Contributing

If you would like to contribute to the translations, please follow
these steps:

1. Create a new branch for your translation
2. Translate the documentation
3. Commit your changes
4. Push your changes to your fork
5. Create a pull request

Please note that all translations must adhere to the project's
code of conduct and be submitted in accordance with the project's
licensing terms.

For more information, please see the [Cloud-init Code of
Conduct](https://cloudinit.readthedocs.io/en/latest/code_of_conduct.html)
and [Cloud-init License](https://cloudinit.readthedocs.io/en/latest/license.html).
