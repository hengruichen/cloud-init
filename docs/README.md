# Cloud-Init Documentation

Welcome to the Cloud-Init documentation!

## Overview

Cloud-Init is a system for configuring cloud instances at startup. It is
used by many cloud providers and is the default configuration system for
Ubuntu and Debian cloud images.

## Documentation Structure

The documentation is organized into the following sections:

- [Installation](installation.md): How to install and configure
  Cloud-Init.
- [Configuration](configuration.md): How to configure
  Cloud-Init.
- [Examples](examples.md): Examples of how to use
  Cloud-Init.
- [Troubleshooting](troubleshooting.md): How to troubleshoot
  Cloud-Init issues.
- [API Reference](api-reference.md): The API reference for
  Cloud-Init.
